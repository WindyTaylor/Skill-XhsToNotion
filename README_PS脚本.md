# PowerShell测试脚本 - 小红书转Notion

## 📁 脚本文件列表

### 0. 执行策略设置
- **文件**: `0_执行策略设置.ps1`
- **功能**: 设置PowerShell执行策略，允许运行脚本
- **使用**: 如果遇到"禁止运行脚本"错误，先运行此脚本

### 1. 连接测试
- **文件**: `1_连接测试.ps1`
- **功能**: 测试Notion API连接和数据库权限
- **使用**: 验证API密钥和数据库ID是否正确

### 2. 保存测试
- **文件**: `2_保存测试.ps1`
- **功能**: 测试保存小红书笔记到Notion
- **使用**: 连接测试成功后，测试保存功能

### 3. 属性检查
- **文件**: `3_属性检查.ps1`
- **功能**: 详细检查数据库属性类型
- **使用**: 确认数据库属性设置正确

### 4. 环境变量设置
- **文件**: `4_环境变量设置.ps1`
- **功能**: 设置Notion环境变量
- **使用**: 为OpenClaw配置环境变量

## 🚀 使用步骤

### 步骤1：允许运行脚本
```powershell
# 方法1：运行设置脚本
.\0_执行策略设置.ps1

# 方法2：直接设置（临时）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 步骤2：测试连接
```powershell
.\1_连接测试.ps1
```
**预期结果**: ✅ 连接成功！

### 步骤3：检查属性
```powershell
.\3_属性检查.ps1
```
**检查要点**:
- 第一列必须是 `title` 类型
- `链接` 列必须是 `url` 类型
- `简介` 列最好是 `text` 或 `rich_text` 类型

### 步骤4：测试保存
```powershell
.\2_保存测试.ps1
```
**预期结果**: ✅ 保存成功！
**验证**: 检查Notion数据库是否出现新记录

### 步骤5：设置环境变量
```powershell
.\4_环境变量设置.ps1
```
**用途**: 为OpenClaw配置环境变量

## 📋 故障排除

### 问题1：执行策略错误
```
无法加载文件...，因为在此系统上禁止运行脚本。
```
**解决**:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 问题2：连接失败 (HTTP 403)
```
❌ 连接失败: 远程服务器返回错误: (403) 禁止访问。
```
**解决**:
1. 确认数据库已分享给 `Xhs` 集成
2. 在Notion中: Share → Invite → 搜索 `Xhs`
3. 点击 `Invite`

### 问题3：保存失败
```
❌ 保存失败: 远程服务器返回错误: (400) 错误的请求。
```
**解决**:
1. 运行 `3_属性检查.ps1` 确认属性类型
2. 确认使用正确的属性名称
3. 检查JSON格式是否正确

### 问题4：属性类型错误
```
错误: 属性类型不匹配
```
**解决**:
1. 在Notion中修改属性类型
2. `链接` 列必须为 URL 类型
3. `简介` 列最好为 Text 类型
